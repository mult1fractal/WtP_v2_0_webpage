Features

Built for wet labs, bioinformaticians & phage therapy

Reproducible, containerized and scaleable - from a laptop to a compute cluster or the cloud.

One command, full stack

--end_to_end chains every module automatically: identify, QC, annotate, classify, detect prophages, predict host and lifecycle.

Modular by design

Independent workflow flags let you run only what you need:

  • --identify · --annotation
  • --taxonomy · --prophage
  • --host · --lifecycle

Databases, automatic

Reference databases auto-download on first run and are available for subsequent runs - they don't need to be downloaded every time.

Interactive HTML report

Overview, quality, identification, annotation genome viewer (linear & circular), taxonomy, prophage and lifecycle - plus per-sample JSON for downstream use.

Scales: laptop → HPC → cloud

Profiles for local, slurm, lsf, ebi and Google Batch, with docker or singularity engines.

Reproducible

Containerized tools, pinned Nextflow and CI-tested stub profiles make every run reproducible and fast to test.

Install Java and Nextflow 
# install java and nextflow
sudo apt-get update
sudo apt install -y default-jre
curl -s https://get.nextflow.io | bash
sudo mv nextflow /usr/bin/
Install Docker Engine 
# Add Docker's official GPG key:
sudo apt update
sudo apt install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Add the repository to Apt sources:
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

sudo usermod -a -G docker $USER
Restart your computer so the Docker group takes effect, then run a quick testrun using the stable release (-r v2.0.0):
Test run 
# -r v2.0.0 = stable release version (pinned for reproducibility)
nextflow run replikation/What_the_Phage -r v2.0.0 --cores 8 -profile smalltest,local,docker
How to run

Three commands cover the spectrum

Requires Nextflow and a container engine. Databases auto-download on first run (≈ 50 GB for the default end-to-end run). Add -resume to cache completed steps.

End-to-end on a laptop 
# full characterization: identify + QC + annotate + taxonomy + prophage + host + lifecycle
# phage.nf = newest changes, run inside the cloned What_the_Phage directory (may be unstable)
# or use the stable release from anywhere: nextflow run replikation/What_the_Phage -r v2.0.0 ...
nextflow run phage.nf \
    --fasta 'contigs/*.fasta' \
    --end_to_end \
    --cores 16 \
    --output results \
    -profile local,docker
HPC cluster (SLURM / Singularity) 
# phage.nf = newest changes, run inside the cloned What_the_Phage directory (may be unstable)
# or use the stable release from anywhere: nextflow run replikation/What_the_Phage -r v2.0.0 ...
nextflow run phage.nf \
    --fasta 'contigs/*.fasta' \
    --end_to_end --cores 20 \
    --output results \
    -profile slurm,singularity \
    --cachedir /images/singularity_images \
    --databases /databases/WtP_databases/
Modular - run only what you need 
# e.g. identification + prophage detection only
# phage.nf = newest changes, run inside the cloned What_the_Phage directory (may be unstable)
# or use the stable release from anywhere: nextflow run replikation/What_the_Phage -r v2.0.0 ...
nextflow run phage.nf \
    --fasta 'contigs/*.fasta' \
    --identify --prophage \
    --output results \
    -profile lsf,singularity

Engines

Everything phage.nf --help knows

The full command-line reference for WtP v2.0. Run nextflow run phage.nf --help on any machine to get this list.

phage.nf --help

--host        run host prediction
--lifecycle   run lifecycle prediction

engines     docker | singularity
